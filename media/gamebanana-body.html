Four Layers Down Co-op

Local two-player co-op for Brave Tower in Five Nights at Frickbear's 3 + Four Layers Down (v2.1.5). Player 1 runs the monitor with the mouse; Player 2 handles the doors, mask and fan with the arrow keys, on the same keyboard.

Features

  • A new Co-op Mode card in the Brave Tower mode picker, always unlocked.
  • Each player picks their own guard (no duplicates), with 3 shared lives: 2 for Player 1's guard and 1 for the helper's.
  • Switch the active guard on the animatronic selection screen, Party Mode style.
  • Roster passives (Jeremy, Vanessa, Michael, Vannabelle) belong to the active guard. Every other passive works for both guards while they're alive.
  • The Boss, Sally and Mary change how a night is won, so they don't stack: if both guards have one, the helper's rule wins.
  • The helper's guard shows up in the monitor reflection, next to Player 1's.
  • Dollie's healing works for both guards, and Co-op runs are saved so you can continue them later.

Controls

  • Player 1: mouse + your usual keys (monitor, cameras, flashlight, turn around, Esc to pause).
  • Player 2, in the office: ← left door · → right door · ↓ mask · ↑ fan.
  • Guard select: Player 1 clicks a guard (1P); the helper moves the 2P frame with the arrows.
  • Animatronic select: the helper presses ← / → to switch the active guard.

The original rules still apply: no mask while the monitor is up, and no monitor while the mask is on (you'll hear an error sound).

Installation

Requires the original v2.1.5 game with no other mods installed.

  1. Close the game and back up your data.win.
  2. Open DeltaPatcher. Original file: the data.win next to Frickbears3.exe. XDelta patch: FourLayersDownCoop-v1.1.xdelta.
  3. Click "Apply patch". If it fails, your data.win isn't a clean 2.1.5.

To uninstall, restore your backup. A saved Co-op run continues as a normal Solo run on the original game.

Notes

  • Some keyboards drop keys when many are held at once. A second USB keyboard for the helper fixes it, since the game reads every keyboard.
  • On-screen key hints still show Player 1's keys.
